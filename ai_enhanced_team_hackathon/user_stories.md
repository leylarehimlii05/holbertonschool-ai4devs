# User Stories - CodePulse Hackathon MVP

## User Story 1
As a developer, I want to paste a raw `git diff`, commit log, or error stack trace into a clean workspace editor so that I can prepare code context for AI analysis in seconds.

## User Story 2
As a developer, I want to select an output mode (`PR Summary`, `Bug Root-Cause`, or `Release Notes`) before generating a report so that the AI formats the response for my exact workflow.

## User Story 3
As a developer, I want the AI to generate a structured Markdown summary containing an overview, risk level (`Low`, `Medium`, `High`), affected components, and a review checklist so that my pull requests are thorough and consistent.

## User Story 4
As a developer, I want to copy the generated Markdown report to my clipboard with a single click so that I can paste it directly into GitHub, GitLab, or Slack without manual formatting.

## User Story 5
As a developer or tech lead, I want to download the generated summary as a `.md` file so that I can archive release notes or incident postmortems locally.

## User Story 6
As a team member, I want to view a shared feed of recently generated summaries so that teammates can catch up on recent PRs and incidents without re-running prompts.

## User Story 7
As a team member, I want to filter and search past summaries by output mode (`PR Summary`, `Bug Root-Cause`, `Release Notes`) or keyword so that I can quickly locate prior analyses.

## User Story 8
As a developer, I want to tag each generated summary with a repository or service name so that multi-repo teams can keep summaries organized.

## User Story 9
As a developer, I want clear validation alerts and loading indicators while the AI processes my input so that I know when a request is running or if input size limits are exceeded.

## User Story 10
As a mobile or desktop hackathon judge/user, I want a responsive interface that renders syntax-highlighted diffs and Markdown previews cleanly across screen sizes.
