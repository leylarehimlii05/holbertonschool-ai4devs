# User Stories - SprintPulse MVP

## User Story 1
As a developer, I want to join a workspace using a workspace access code and my display name so that I can participate in daily standups without creating a complex account.

## User Story 2
As a developer, I want to submit a structured daily check-in (Yesterday, Today, Blockers) through a simple form so that I can share my status in under 60 seconds.

## User Story 3
As a developer, I want to assign a severity level (`None`, `Minor`, `Critical`) to my blocker so that the team immediately understands its urgency.

## User Story 4
As a tech lead, I want active blockers to be automatically pinned and highlighted at the top of the dashboard so that urgent impediments are never overlooked.

## User Story 5
As a team member, I want to view all daily standup updates grouped by date in a clean feed so that I can catch up asynchronously on team progress.

## User Story 6
As a team lead, I want to search and filter check-ins by team member name, date, or blocker status (`All`, `Blocked Only`, `Resolved`) so that I can quickly find relevant updates.

## User Story 7
As a developer or tech lead, I want to mark a blocker as resolved with a single click so that the team knows the impediment has been cleared and when it was resolved.

## User Story 8
As a developer, I want to edit or delete my own check-in entry on the same day so that I can fix typos or update my plan if priorities shift.

## User Story 9
As a project manager, I want to export a selected day's or week's check-ins as Markdown or CSV so that I can paste summaries into Slack/Notion or analyze them in sprint retrospectives.

## User Story 10
As a mobile or desktop user, I want the application interface to be responsive and provide clear visual feedback (toasts/validation errors) so that I can submit and review updates seamlessly on any device.
